## 4. 解除阻塞的路径

### 4.1 路径 A：聚宽 JQ 模拟盘/实时数据（推荐）

**优势**：
- 与母版策略语义最一致（006G 已验证字段对齐）
- 覆盖竞价、涨跌停、ST、停牌、market_cap、分钟数据
- 不需要券商 API 即可做观察盘（第一层不下单）

**劣势**：
- 不能直接执行实盘订单（第二层 pilot 仍需券商）
- 需要 JQ 实时数据订阅
- JQ 模拟盘成交可能与实盘有差异

**适用阶段**：第一层观察盘（E6）

### 4.2 路径 B：券商 API + 行情接口

**优势**：
- 最接近实盘执行
- 可覆盖订单提交/成交回报/持仓现金

**劣势**：
- 用户明确无接入能力
- 字段对齐工作量大（券商行情 vs HData 语义差异）
- 需要 QMT/华泰/东财等具体券商支持

**适用阶段**：第二层 pilot（E7 后）

### 4.3 路径 C：第三方行情 + 手动下单

**优势**：
- 数据源可灵活选择（Wind/Tushare Pro/同花顺等）
- 不依赖券商 API 即可做观察盘

**劣势**：
- 字段对齐需逐项验证
- 第二层 pilot 仍需手动下单（半自动）
- 第三方行情可能不覆盖竞价量

**适用阶段**：第一层观察盘（备选）
