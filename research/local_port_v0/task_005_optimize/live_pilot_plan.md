TASK-006D §5: 实盘试运行方案
=============================

> 基于 TASK-006D 全部分析结果，给出三档实盘试运行方案。
> 保守版优先满足：最大回撤≤20%、初始资金不超过容量保守上限、2026式退化可停机。

---

## 1. 方案总览

| 维度 | 保守版 | 中性版 | 激进版 |
|------|--------|--------|--------|
| 建议初始资金 | **50万** | 80万 | 100万 |
| 最大允许资金 | 80万 | 100万 | 150万 |
| 仓位系数 | **80%** | 90% | 100% |
| 单票最大仓位 | 5% | 8% | 10% |
| 总持仓数量上限 | 30只 | 25只 | 20只 |
| 单日最大换手 | 30% | 40% | 50% |
| 单日最大亏损 | -3% | -4% | -5% |
| 月度最大亏损 | -8% | -10% | -12% |
| 最大回撤停机线 | **-15%** | -18% | -20% |
| 连续亏损停机线 | 5天 | 5天 | 3天 |
| 观察期长度 | 20交易日 | 10交易日 | 5交易日 |
| 允许自动下单 | **否**（观察期后是） | 是 | 是 |
| 需要人工确认 | 每笔 | 每日汇总 | 异常时 |

## 2. 保守版（推荐）

### 2.1 参数依据

| 参数 | 值 | 依据 |
|------|-----|------|
| 初始资金 | 50万 | 容量测试：1M资金下仅30.78%买入交易在5%竞价参与率内；50万可提升至~50% fill rate |
| 仓位系数 | 80% | risk_control_scenarios: pos_80 → max_dd -18.86%, CAGR 37.8%，满足≤20% |
| 单票最大仓位 | 5% | 微盘股流动性约束，避免单票集中 |
| 最大回撤停机线 | -15% | pos_80方案max_dd为-18.86%，-15%留缓冲 |
| 连续亏损停机 | 5天 | 2026年退化期间连续亏损频繁 |
| 观察期 | 20交易日 | 2026年退化需滚动窗口识别 |

### 2.2 风控规则

1. **仓位缩放**：所有订单数量 × 0.8
2. **回撤熔断**：累计回撤 > 10% 时降仓到50%，回撤修复到 < 5% 时恢复80%
3. **月度保护**：当月亏损 > 8% 时，本月剩余时间降仓到50%
4. **竞价参与率**：单票买入不超过该票竞价成交量的 5%
5. **观察期**：前20个交易日仅模拟盘运行，不实际下单；观察期结束后评估滚动胜率和滚动收益

### 2.3 停机条件（任意一条触发即停机）

- 累计回撤 > -15%
- 连续亏损天数 ≥ 5
- 20日滚动胜率 < 35%
- 20日滚动收益 < -5%
- 20日最大回撤 < -12%
- 订单拒绝率 > 40%

### 2.4 恢复条件

- 停机后至少观察20个交易日
- 所有停机指标恢复到警戒阈值以内
- 人工审核确认市场环境未发生结构性变化

## 3. 中性版

### 3.1 参数依据

| 参数 | 值 | 依据 |
|------|-----|------|
| 初始资金 | 80万 | 容量测试：80万在10%参与率下fill rate ~42% |
| 仓位系数 | 90% | pos_80和pos_100之间的折中 |
| 最大回撤停机线 | -18% | 介于pos_80(-18.86%)和gross(-23.20%)之间 |

### 3.2 与保守版的差异

- 仓位更高（90% vs 80%），收益更高但回撤也更大
- 允许自动下单（观察期后）
- 人工确认降为每日汇总
- 单票仓位放宽到8%

---

## 4. 激进版

### 4.1 参数依据

| 参数 | 值 | 依据 |
|------|-----|------|
| 初始资金 | 100万 | 回测原始资金，但容量约束严重 |
| 仓位系数 | 100% | 不缩放，max_dd -23.20% |
| 最大回撤停机线 | -20% | 接近gross max_dd，缓冲小 |

### 4.2 风险提示

- 100%仓位在gross口径下max_dd为-23.20%，已超过-20%目标
- 30bp成本后max_dd扩大到-26.02%
- 容量约束严重：1M资金下仅30.78%买入在5%参与率内
- **不推荐**：除非策略确认已度过2026年退化期

---

## 5. 通用规则（三档共用）

### 5.1 竞价参与率约束

所有方案必须遵守：
- 单票买入量 ≤ 该票竞价成交量 × 5%（保守）/ 10%（中性）/ 20%（激进）
- 若竞价成交量过小（<100手），跳过该票

### 5.2 资金容量上限

| 方案 | 初始资金 | 最大资金 | 容量依据 |
|------|----------|----------|----------|
| 保守 | 50万 | 80万 | 5%竞价参与率，50% fill rate |
| 中性 | 80万 | 100万 | 10%竞价参与率，42% fill rate |
| 激进 | 100万 | 150万 | 20%竞价参与率，54% fill rate |

### 5.3 2026退化监控

所有方案必须实时监控：
- 20日滚动胜率（停机阈值35%）
- 20日滚动收益（停机阈值-5%）
- 连续亏损天数（停机阈值5天）
- 一旦触发，立即停机转模拟盘

---

## 6. 推荐方案

**保守版（50万，80%仓位）**

理由：
1. 最大回撤 -18.86%（pos_80），满足≤20%目标
2. CAGR 37.8%，满足≥25%最低要求
3. 初始资金50万，容量约束相对宽松
4. 观察期20天，可识别2026式退化
5. 多重停机机制，风险可控
6. 不自动下单（观察期内），人工介入
