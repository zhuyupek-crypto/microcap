## 1. 成本后净值是否仍有效？

**仍有效，但收益有所下降。**

基于全区间（2020-01-01 ~ 2026-05-28）的**每日净值级**成本重算（非006C的期末一次性扣除）：

| 场景 | CAGR | 最大回撤 | 夏普 | Calmar | 总成本 |
|------|------|----------|------|--------|--------|
| gross | 48.33% | -23.20% | 1.76 | 2.08 | 0 |
| 10bp | 47.40% | -23.94% | 1.68 | 1.98 | 43.8万 |
| 20bp | 46.44% | -24.92% | 1.60 | 1.86 | 87.6万 |
| 30bp | 45.45% | -26.02% | 1.53 | 1.75 | 131.4万 |
| 50bp | 43.33% | -28.38% | 1.37 | 1.53 | 219.0万 |

**关键发现（与006C的差异）**：
- 006C的成本敏感性是**期末一次性扣除**，回撤形态不变
- 006D是**每日扣除当日成交成本**，累计成本影响每日净值
- **成本后最大回撤显著扩大**：gross -23.20% → 30bp -26.02% → 50bp -28.38%
- **最大回撤区间发生变化**：gross是2024-05-17~06-24，但30bp后变成2025-11-17~2026-03-23
- 这说明2025年底-2026年初的回撤在成本后更严重

**结论**：即使50bp成本，CAGR仍为43.33%，策略仍有效。但成本后回撤扩大，不容忽视。

## 3. 策略容量上限大约是多少？

**容量严重受限。即使100万资金，也只有约30%的买入交易在5%竞价参与率内。**

基于全区间4753笔已匹配交易的竞价参与率分析（买入仅）：

| 统计量 | 值 |
|--------|-----|
| 买入最大参与率 | 46.0x（4600%，极端异常值） |
| 买入P95参与率 | 3.63x（363%） |
| 买入中位参与率 | 0.161（16.1%） |
| 卖出最大参与率 | 89.27x（8927%） |

资金×参与率矩阵（买入fill rate）：

| 资金 | 5%限制 | 10%限制 | 20%限制 | 30%限制 |
|------|--------|---------|---------|---------|
| 100万 | 30.78% | 42.47% | 53.74% | 60.71% |
| 300万 | 16.30% | 25.13% | 35.25% | 42.12% |
| 500万 | 11.15% | 18.27% | 27.78% | 33.64% |
| 1000万 | 6.65% | 11.15% | 18.27% | 23.63% |
| 2000万 | 3.97% | 6.65% | 11.15% | 14.98% |
| 5000万 | 1.79% | 3.18% | 5.65% | 7.58% |

**容量上限**（基于竞价成交额，非全天成交额）：

| 方案 | 资金上限 | 规则 |
|------|----------|------|
| 保守 | **50万** | 5%竞价参与率，约50% fill rate |
| 中性 | **80万** | 10%竞价参与率，约42% fill rate |
| 激进 | **100万** | 20%竞价参与率，约54% fill rate |

**重要说明**：
- 容量基于**开盘竞价成交量**（09:25快照），不是全天成交量
- 买入中位参与率16.1%已超过10%限制，说明策略在1M回测中已接近容量极限
- 卖出参与率更高（最大89x），因为卖出不受竞价量约束（按持仓量决定）
- 实盘中卖出同样面临流动性约束，实际fill rate会更低

## 4. 哪个仓位/风控方案最适合实盘？

**80%固定仓位缩放（pos_80）最适合。**

7种风控方案对比（全区间）：

| 方案 | CAGR | 最大回撤 | 夏普 | Calmar | ≤20%? | CAGR≥25%? | 推荐? |
|------|------|----------|------|--------|-------|-----------|-------|
| pos_100 | 48.29% | -23.20% | 1.76 | 2.08 | 否 | 是 | 否 |
| **pos_80** | **37.80%** | **-18.86%** | **1.69** | **2.00** | **是** | **是** | **是** |
| pos_60 | 27.70% | -14.38% | 1.60 | 1.93 | 是 | 是 | 是 |
| pos_50 | 22.81% | -12.08% | 1.54 | 1.89 | 是 | 否 | 否 |
| dd_breaker_10pct | 33.93% | -16.99% | 1.44 | 2.00 | 是 | 是 | 是 |
| dd_breaker_8pct | 33.95% | -16.99% | 1.48 | 2.00 | 是 | 是 | 是 |
| monthly_loss_8pct | 45.60% | -22.92% | 1.75 | 1.99 | 否 | 是 | 否 |

**推荐pos_80的理由**：
1. 最大回撤-18.86%，满足≤20%目标
2. CAGR 37.80%，远超25%最低要求
3. 夏普1.69，风险调整后收益优秀
4. Calmar 2.00，回撤效率高
5. 实现简单（固定仓位缩放），无需复杂熔断逻辑
6. 不会像熔断方案那样在回撤后错过反弹

**备选方案**：dd_breaker_10pct（回撤>10%降仓50%），max_dd -16.99%，CAGR 33.93%，回撤更低但收益也更低。

## 6. 建议初始实盘资金是多少？

**50万（保守版）。**

依据：
1. **容量约束**：100万资金下仅30.78%买入交易在5%竞价参与率内；50万可提升至约50%
2. **风控需求**：80%仓位下max_dd -18.86%，50万对应绝对回撤约9.4万，可承受
3. **试运行性质**：首期实盘应小资金验证，不追求规模
4. **容量上限**：保守方案最大允许资金80万，50万留扩容空间

## 7. 是否允许进入小资金实盘试运行？

**允许，但有条件。**

决策口径：**允许小资金实盘试运行**

条件：
1. 使用保守版方案（50万，80%仓位）
2. 前20个交易日为强制观察期，不自动下单
3. 必须确认2026年退化期已结束（20日滚动胜率>50%）
4. 建立停机机制（回撤>15% / 连续亏损≥5天 / 滚动胜率<35%）
5. 实盘前完成检查清单（见 live_pilot_plan.md §7）

理由：
- 策略在2020-2025年表现强劲（CAGR 37.8%-48.3%），统计显著
- pos_80方案可将回撤压至-18.86%，满足≤20%
- 容量虽受限，50万小资金可行
- 2026年退化风险可通过观察期和停机机制管理
