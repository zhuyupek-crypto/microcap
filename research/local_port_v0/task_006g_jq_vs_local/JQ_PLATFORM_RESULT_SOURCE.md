## 3. 起始日期反推

虽然没有聚宽原始回测报告，但可以通过CAGR公式反推近似起始日期：

```
总收益 = 6932.96% = 69.3296倍
CAGR = 68.24%

年数 N = ln(69.3296) / ln(1.6824) = 4.239 / 0.5203 ≈ 8.14年
```

如果结束日期约为 2026-05-28（与本地对齐）：
```
起始日期 ≈ 2026-05-28 往前推 8.14 年 ≈ 2018-03
```

如果结束日期约为 2026-06-30：
```
起始日期 ≈ 2026-06-30 往前推 8.14 年 ≈ 2018-04
```

**高概率推断：聚宽母版回测起始日期约为2018年初，比本地2020-01-01早约2年。**

但这是基于CAGR公式的数学反推，不是直接证据。

## 5. 结论

### 已证明
- 本地没有聚宽68.24%的原始回测报告
- 聚宽68.24%只能作为C级宏观参考

### 高概率
- 聚宽母版回测起始日期约为2018年初（CAGR反推）
- 聚宽与本地存在约2年的区间差异

### 不能证明
- 聚宽68.24%与本地48.33%是否完全同区间
- 聚宽年化/夏普/回撤的计算口径是否与本地一致
- 差异中有多少来自区间、多少来自数据/成交/统计口径

## 6. 对后续阶段的约束
