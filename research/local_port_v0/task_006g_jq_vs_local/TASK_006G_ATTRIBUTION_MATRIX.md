## 3. 三层结论

### 3.1 已证明（A 级证据）

1. **策略代码相同**：母版策略 git SHA 7a72ae2，2020-01-01~2026-05-28 区间内未修改
2. **本地 Research 与 jq_parity 相同**：006F-A 已证实两引擎模式结果完全一致
3. **2025 年交易级对齐达成 A 级**：651 行逐笔对比，55.91% 完全匹配，85% 数量差异是 JQ 导出缺陷
4. **2026 片段对齐达成 A 级**：05-06~05-13 完全对齐，05-14 首分叉精确归因
5. **成交模型 16 维度一致**：无系统性差异
6. **统计口径公式一致**：反向重算结果完全一致，贡献=0
7. **数据源已量化部分贡献 < 0.02pp**：14:00 价差 + ETF 精度（已消除）

### 3.2 高概率（B 级证据）

1. **聚宽 68.24% 与本地 48.33% 的差异，主要来自区间差异**：聚宽起始约 2018-03，多包含 2018-2019 两年贡献约 523%，对应约 15-18pp 年化贡献
2. **数据源差异（market_cap、call_auction 缺失）有补充贡献**：无法严格量化，但推测约 2-5pp
3. **本地 Research 适合作为实盘基线**：成交模型、统计口径与聚宽一致，数据源差异已诊断且部分已修复

### 3.3 不能证明（C 级证据）

1. **无法做全周期 A 级逐笔归因**：聚宽 68.24% 只有摘要数字，缺完整净值曲线和逐笔交易
2. **无法精确量化数据源差异的全周期贡献**：market_cap 差异、call_auction 缺失、全周期信号分叉累积均无法严格量化
3. **不能声称已完全解释 19.91pp 年化差异**：已量化 ~15-18pp（区间），未量化 ~2-5pp（数据源组合），仍有不确定性
4. **不能把 2026 片段结论外推到全周期**：片段方向与全周期相反，机制特殊

## 4. 关键限制

- 本地无聚宽原始回测报告

- 无聚宽完整逐笔交易
