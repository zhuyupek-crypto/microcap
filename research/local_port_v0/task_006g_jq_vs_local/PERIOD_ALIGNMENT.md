## 2. CAGR反推计算

### 2.1 方法

已知聚宽母版：
```
total_return = 6932.96% → final/initial = 70.3296
CAGR = 68.24% → annual_multiplier = 1.6824
```

CAGR公式：
```
final/initial = (1 + CAGR)^N
N = ln(final/initial) / ln(1 + CAGR)
N = ln(70.3296) / ln(1.6824)
N = 4.2535 / 0.5203
N ≈ 8.17年
```

### 2.2 起始日期推算

| 结束日期假设 | 反推起始日期 |
|--------------|-------------|
| 2026-05-28 | 2018-03-15 |
| 2026-06-30 | 2018-04-16 |
| 2026-12-31 | 2018-10-15 |

**最可能：聚宽母版起始日期约为2018年1-3月。**

### 2.3 验证

如果聚宽从2018-01-01开始到2026-05-28（约8.4年）：
```
预期CAGR = 70.3296^(1/8.4) - 1 = 75.6%
```
与68.24%不完全匹配，差异可能来自：
- 实际起始日期稍晚（2018-03~06）
- 或聚宽年化公式不同（如用实际交易日而非日历年）

如果从2018-03-01到2026-05-28（约8.23年）：
```
预期CAGR = 70.3296^(1/8.23) - 1 = 69.3%
```
接近68.24%，差异0.9pp在合理误差范围内。

## 3. 2018-2019年贡献估算

### 3.1 微盘股市场环境

2018-2019年A股微盘股市场：
- 2018年：A股熊市，上证综指全年跌24.59%，但微盘股策略因反转效应可能仍有正收益
- 2019年：A股结构性牛市，小盘股年初暴涨，中证1000全年涨25.67%

### 3.2 区间贡献数学分解

假设聚宽从2018-01开始，本地从2020-01开始：

```
聚宽总倍数 = 70.33
本地总倍数 = 11.29 (1028.65% + 1)

2018-2019年贡献倍数 = 70.33 / 11.29 = 6.23倍

即2018-2019两年贡献了约523%的收益
```

这意味着如果2018-2019年收益约为523%（两年复合）：
```
年均 = sqrt(6.23) - 1 = 149.6%
```

这在小盘股策略的早期阶段是可能的（2019年初小盘股暴涨），但偏高。

### 3.3 替代假设

如果聚宽起始日期更晚（如2018年中），2018-2019贡献会减少：
```
假设2018-07开始，2018-2019约1.5年
贡献倍数仍为6.23
年均 = 6.23^(1/1.5) - 1 = 273%（更高，不太合理）
```

如果聚宽起始日期更早（如2017年）：
```
假设2017-01开始，2017-2019约3年
贡献倍数 = 6.23
年均 = 6.23^(1/3) - 1 = 83.3%（更合理）
```

### 3.4 结论

**2018-2019（或更早）的区间差异极可能是聚宽68.24% vs 本地48.33%差异的主要来源之一。**

但无法严格量化，因为：
- 没有聚宽2018-2019的净值曲线
- 没有聚宽实际起始日期的直接证据
- 本地call_auction数据从2020开始，无法本地复跑2018-2019

## 6. 结论

### 已证明（A级）
- 本地母版起始日期为2020-01-01，结束日期为2026-05-28
- 本地无法回测2020年之前（HData数据限制）
- 聚宽与本地结束日期推测一致

### 高概率（B级）
- 聚宽母版起始日期约为2018年初（CAGR反推，约8.17年）
- 区间差异是聚宽68.24% vs 本地48.33%差异的主要来源之一
- 2018-2019年贡献了约523%的额外收益（数学分解）

### 不能证明（C级）
- 聚宽母版的实际起始日期
- 2018-2019年的实际收益贡献
- 区间差异在20pp年化差异中的精确占比
